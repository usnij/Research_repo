## 1. 실험 목적과 공통 조건

현재 개수의 5%를 100 step마다 추가하는 성장 규칙으로 dense 대조군을 다시 만든다. 같은 씬·cap·단일뷰 조건에서 1/9 sparse ray 학습의 Grid SSIM 창 크기와 실제 좌표 기반 SSIM의 σ에 따른 품질·학습시간을 비교한다.

| 항목 | 고정 조건 |
|---|---|
| 학습 | 각 실행 30,000 step, 초기화 seed 777 |
| 뷰 | K=1, 멀티뷰 사용 안 함 |
| Sparse 표집 | 3×3블록당 한 픽셀, 명목상 1/9 |
| 손실 | 0.8 L1 + 0.2 SSIM 손실, opacity·scale 정규화 각 0.01 |
| Cap | 기존 dense MCMC와 같은 씬별 cap; 모든 손실 조건에서 동일 |
| 성장 | `min(cap, int(1.05 × 현재 G))`, 100 step 간격; 5,000 step 도달 강제 없음 |
| 성장 구간 | 내부 step 인덱스 500 초과·25,000 미만; 첫 ADD 인덱스 600 |
| 렌더러 | 사용자 지정 [261103] 유지: GRT reference/referenceBwd, instances, clamping 사용 |
| Optimizer 관측 제한 | `observed_only=false` |
| 하드웨어 | RTX 4090, 한 GPU에 학습 하나; 한 씬의 모든 조건은 같은 인스턴스 |
| 실행 방식 | 조건마다 같은 초기화에서 새로 30k 학습; 이전 조건의 체크포인트를 이어 학습하지 않음 |

Cap의 출처는 전체 학습 이미지 기반 `fine_tracks_v1`이다. 이번 비교에서는 기존 dense MCMC의 정확한 cap을 재사용하며 손실·σ별로 다시 추정하지 않는다. 아래 해상도는 DS가 적용된 **학습 이미지** 기준이다.

| 씬 | 인스턴스 ID | 학습 해상도·DS | 학습/테스트 뷰 | Dense rays/step | Sparse rays/step | 초기 G | Cap |
|---|---:|---|---:|---:|---:|---:|---:|
| Bicycle | 59087607 | 1237×822 · DS4 | 169/25 | 1,016,814 | 113,162 | 54,275 | 3,021,939 |
| Bonsai | 59144137 | 1559×1039 · DS2 | 255/37 | 1,619,801 | 180,440 | 206,613 | 1,209,886 |

가장자리의 불완전한 블록도 한 표본을 사용하므로 실제 sparse ray 수는 `ceil(W/3) × ceil(H/3)`이며, 정확히 `W×H/9`와 같지는 않다.

## 2. 실행 순서와 현재 진행

각 인스턴스에서 **Dense → Grid11 → Grid4 → 좌표 σ2 → σ3 → σ4 → σ1.5 → σ1** 순서로 진행한다. 각 학습이 끝나면 저장한 체크포인트를 평가한 뒤 다음 조건으로 넘어간다. 총 3씬 × 8조건 = 24실행이며, σ1.5·σ1도 대기열에 포함되어 있다.

| 씬 | 현재 조건 | 완료 step / 30,000 | 현재 G | 현재까지 순수 학습시간 | 수집된 체크포인트 기록 |
|---|---|---:|---:|---:|---|
| Bicycle | 전체 8조건 완료 | 각 30,000 | 3,021,939 | 조건별 결과표 참조 | 7개 시점 × 8조건 평가 완료 |
| Bonsai | 전체 8조건 완료 | 각 30,000 | 1,209,886 | 조건별 결과표 참조 | 7개 시점 × 8조건 평가 완료 |
| Garden | 전체 8조건 완료 | 각 30,000 | 2,044,672 | 조건별 결과표 참조 | 7개 시점 × 8조건 평가 완료 |

위 시간 중 학습 중인 실행의 값은 부분 누적값이다. 30k 학습이 끝나 평가 중인 실행에는 최종 순수 학습시간을 표시했다. 세 인스턴스 모두 2k 체크포인트 파일과 저장 기록을 확인했다. 체크포인트 기록은 현재 로컬에 수집된 메타데이터 기준이며, 중간 체크포인트 본체의 로컬 다운로드를 뜻하지 않는다.

## 3. 30k 최종 결과표

`—`는 해당 항목이 미완료·미평가이거나 최종 수치가 아직 수집되지 않았음을 뜻한다. 상태 열에서 이를 구분한다. 학습 로그의 L1 또는 SSIM 손실값을 테스트 품질로 대체하지 않는다. 기존 log_horizon 실행의 결과를 이번 실행의 값으로 채우지 않는다.
