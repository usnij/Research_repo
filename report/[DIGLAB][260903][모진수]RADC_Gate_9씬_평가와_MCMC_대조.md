# RADC-Gate 의 9개 씬 평가와 MCMC 대조

작성 2026-09-03. 인스턴스 8대와 로컬 RTX 4070 SUPER 를 동시에 사용해 학습했다.
PSNR, SSIM, LPIPS 는 학습 로그가 아니라 저장된 체크포인트를 `eval_full.py` 로 다시
평가한 값이다. 

## 요약

이번 리포트의 핵심 발견은 세 가지다.

### 발견 1 — sampling 비율 1/16 과 RADC-Gate 로 9개 씬 전부에서 dense 학습의 품질을 유지하면서 Gaussian 수를 줄였다

실외 5개 씬은 dense 학습 대비 Gaussian 수가 27.0 ~ 57.1% 이고 PSNR 차이는
−0.108 dB 에서 +0.365 dB 다. treehill 은 Gaussian 이 dense 의 9,739,164개에서
2,625,969개로 27.0% 까지 감소했는데 PSNR 은 22.039 dB 에서 22.307 dB 로
0.268 dB 증가했다. 실내 4개 씬은 Gaussian 수가 dense 의 86.5 ~ 99.6% 이고
PSNR 차이는 −0.094 dB 에서 +0.498 dB 다.

실내와 실외의 감소폭 차이는 dense 학습 자체의 Gaussian 수에서 온다. 실외
dense 는 4,206,710개에서 9,739,164개인 반면 실내 dense 는 1,204,903개에서
1,497,515개다. **실외 dense 학습이 이미 과잉 생성 상태이고, 그만큼 줄일 여지가
크다.**

### 발견 2 — Gaussian 수를 같게 맞춘 MCMC 는 8개 씬 모두에서 우리보다 PSNR 이 높고, 학습 시간은 2.2 ~ 6.5배 길다

MCMC 의 `strategy.add.max_n_gaussians` 를 우리 결과의 Gaussian 수로 설정해
dense Ray 로 학습했다. 여덟 씬 모두 MCMC 가 최종 Gaussian 수를 오차 0으로
맞췄다. kitchen 은 학습 중이다.

PSNR 차이는 bonsai 에서 0.132 dB, counter 에서 0.378 dB, garden 에서 0.469 dB, flowers 에서 0.506 dB, treehill 에서 0.543 dB, stump 에서 0.629 dB, bicycle 에서 0.706 dB, room 에서 0.812 dB 로 MCMC 가 높다. SSIM 도 0.0132 에서 0.0732 만큼 MCMC 가 높다.

학습 시간은 garden 에서 MCMC 60분 대 우리 27분, treehill 에서 62분 대 18분,
flowers 에서 64분 대 18분, bicycle 에서 74분 대 24분, stump 에서 90분 대 24분,
bonsai 에서 97분 대 38분, room 에서 106분 대 18분, counter 에서 110분 대 17분이다.

**Gaussian 수만으로 비교하면 MCMC 가 앞서고, 학습 시간을 함께 보면 우리가 2.2 ~ 6.5배 빠르다.**



### 발견 3 — 최적 block 은 씬마다 다르고, θ = 1.0 에서의 block 비교는 최종 순위와 일치하지 않는다

block 을 고정하고 θ 만 바꾼 결과에서, garden 은 block 4 가 θ = 1.0 일 때
PSNR 이 dense 대비 −0.484 dB 인데 θ = 1.5 에서 −0.028 dB 로 회복된다. 같은
block 을 θ 만 바꿔 0.456 dB 가 달라진다. block 3 은 θ = 1.0 에서 +0.209 dB 로
block 4 보다 앞서지만, θ 를 올린 뒤에는 두 block 의 차이가 0.1 dB 이내로
줄어든다.

원인은 게이트 임계값 θ 가 h̄ (관측된 step 당 평균 Ray 적중 수) 에 대한 절대값이라는
점이다. h̄ 분포는 Ray 수에 비례해 이동하므로, counter 에서 h̄ 의 중앙값이 block 3
에서 3.9, block 4 에서 2.2, block 6 에서 1.0 이다. 같은 θ = 2.0 이 block 3 에서는
거의 적용되지 않고 block 6 에서는 대부분에 적용된다.

### 지난 리포트 (2026-09-01) 로부터
- 지난번에 알아낸 것: RADC-Gate 가 stump 에서 Gaussian 수를 dense 의 1.531배에서
  0.885배로 줄이고 PSNR 을 유지한다. 게이트를 강하게 적용할수록 미교차 Gaussian
  비율이 26.95 ~ 27.25% 에서 21.28% 로 감소한다.
- 그때 몰랐던 것: 실내 씬에서도 같은 결과가 나오는지, 최적 sampling 비율이 씬마다
  어떻게 다른지, MCMC 와 같은 Gaussian 수에서 비교하면 어느 쪽이 나은지.
- 이번에 하기로 한 것: 9개 씬에서 block 과 θ 를 함께 sweep 하고, MCMC 를 대조군으로
  추가하고, SSIM 을 모든 결과에 포함한다.

### 합의 사항 → 상태
- **[완료] 9개 씬 block 선택 실험** — 실내는 downsampling 2 에서 block 4, 5, 6 을,
  실외는 downsampling 4 에서 block 2, 3, 4, 5 를 학습했다. 실내 4개 씬 중 3개가
  block 4 에서 dense 품질을 유지했고 kitchen 만 block 3 이 필요했다.
- **[완료] θ ablation** — 9개 씬에서 θ 를 1.0, 1.5, 2.0, 3.0, 4.0 으로 sweep 했다.
  총 131건의 결과를 얻었다.
- **[완료] MCMC 대조군** — counter, room, bonsai, garden, stump, bicycle, flowers,
  treehill 8개 씬에서 완료했다. 실외 4개 씬의 1차 시도는 인스턴스 디스크가 가득 차
  실패했고, 체크포인트를 정리한 뒤 재실행했다.
- **[부분] MCMC 대조군 kitchen** — kitchen 은 MCMC 를 실행할 인스턴스를 배정하지
  않은 채 해당 인스턴스를 파기해 누락됐다. 다른 씬과 같은 규칙으로 뽑은 cap
  1,458,894 로 로컬에서 재실행 중이다.
- **[완료] SSIM 과 LPIPS 추가** — 모든 결과에 포함했다. 학습 로그의 값이 `nan`
  이어서 체크포인트에서 다시 평가하는 방식으로 바꿨다.
- **[미착수] online-θ 구현** — online-θ 방식을 구현 실험중에 있으나 고정 θ와 같은 성능이 나오고 있지 않아 이 부분 실험중에 있다.

- 실내 4개 씬의 반복 실행. 현재 전부 1회 실행이고, room 은 실행 간 PSNR 표준편차가

## 1. 실험 설정

| 항목 | 값 |
|---|---|
| 해상도 | 실내 downsampling 2, 실외 downsampling 4 (3DGS, Mip-NeRF 360 관례) |
| sampling | block N sampling, 비율 1/N². `--sparse-from 0` |
| 보정 | RADC (`--hit-shrink --shrink-alpha 1 --online-k`) |
| refinement | 15,000 step 이후 4개 view (`--multiview-k 4 --multiview-from 15000`) |
| densify 임계값 | clone 과 split 모두 0.0002 |
| 학습 길이 | 30,000 step, Gaussian 수 상한 14,000,000 |
| 게이트 | `--radc-gate θ`. densify 주기 동안의 h̄ 가 θ 이하인 Gaussian 을 clone 과 split 후보에서 제외 |
| 반복 | 전부 1회 |

dense 기준선은 실내가 2026-08-16 리포트, 실외가 2026-08-28 리포트의 값이다.
bicycle 만 예외로, 기존 두 실행이 Gaussian 수 상한 3,000,000 과 4,700,000 에
걸린 값이어서 이번에 24GB GPU 에서 상한을 풀어 자연 수렴시켰다. 결과는
6,347,139개, PSNR 24.741 dB 다.

block 4 의 최선이 θ = 2.0 에서 −0.182 dB 인 반면, block 3 은 θ = 4.0 에서
+0.498 dB 다. block 2 도 θ = 1.0 에서 +0.022 dB 로 품질을 유지한다.

이 결과는 2026-08-16 리포트가 측정한 inflation 상수 k 와 일치한다. downsampling 2
에서 k 가 room 0.102, bonsai 0.0914, counter 0.115 인 반면 kitchen 은 0.166 으로
가장 크다. `배율 = sqrt(1 + k/R)` 에서 R 이 같으면 k 가 큰 씬의 inflation 이 크고,
그만큼 촘촘한 sampling 이 필요하다.

kitchen 의 이미지 통계도 같은 방향이다. 학습 이미지의 평균 gradient 크기가
counter 0.01963, room 0.01507, bonsai 0.01791 인 반면 kitchen 은 0.03017 로
두 번째로 큰 counter 의 1.54배다. dense Gaussian 수도 1,497,515개로 실내에서
가장 많고, Ray/Gaussian 비는 1.081 로 가장 낮다.

block 4 에서 MCMC 가 31.525 dB 에서 31.639 dB 로 0.114 dB 높았다고 기록한다.
같은 Ray 수에서는 두 방향의 결과가 모두 관측됐다.

## 4. 게이트 임계값을 자동으로 정하는 세 방식

θ 를 씬마다 선택해야 하는 문제를 없애기 위해 세 가지를 구현했다.

### 4.1 Gaussian 수 목표 제어 (`--gate-target-g`)

densify 주기마다 현재 Gaussian 수를 지수 궤적과 비교해 θ 를 조정한다. Gaussian
수가 입력이 되므로 MCMC 와 같은 조건에서 비교할 수 있고 품질-효율 곡선을 직접
그릴 수 있다. 다만 사용자가 예산을 지정해야 한다는 점에서 MCMC 와 같은 구조다.

### 4.2 h̄ 분위수 제어 (`--gate-quantile`)

θ 를 h̄ 분포의 q 분위수로 정한다. treehill 에서 확인한 결과, 차단 비율이
학습 전 구간에서 45.0% 로 일정하고 θ 는 51.9 에서 4.9 로 자동 조정됐다. 고정 θ
가 학습 초반 0.6% 에서 후반 30.6% 로 변하는 것과 대비된다. block 과 학습 단계에
따른 강도 변화가 사라지므로 block 비교에 사용할 수 있다.

### 4.3 신규 자식 Gaussian 의 낭비율 제어 (`--gate-waste`)

densify 가 생성한 자식 Gaussian 중 다음 주기에 h̄ ≤ 1 인 비율을 측정해 θ 를
조정한다. h̄ = 1 은 관측된 모든 step 에서 Ray 를 하나만 받은 상태이고, 2026-09-01
리포트에서 split-half 로 측정한 신뢰도 ρ 가 0.0001 인 층이다. 학습 진행과
분리된 양이므로 loss 와 달리 반사실 (counterfactual) 이 필요하지 않다.

counter 에서 낭비율 30% 조건이 1,171,293개, PSNR +0.069 dB 로 고정 θ sweep 의
어느 값보다 Gaussian 이 적으면서 PSNR 이 높다. garden 에서는 고정 θ = 2.0 이
2,225,791개, −0.045 dB 로 낭비율 15% 의 2,015,984개, −0.220 dB 보다 낫다.
씬에 따라 결과가 구분된다.

### 4.4 densify 임계값을 inflation 으로 보정 (`--tau-phi`)

τ = 0.0002 는 dense 학습에서 정한 값이고 sparse sampling 은 통계량을 φ 배
증가시키므로 `τ_eff = τ × φ` 를 사용한다. φ 는 `--online-k` 가 갱신하는 k_med 와
h_med 로 계산하며 조절 인자가 없다. 전역 배율이므로 Gaussian 간 순위는 변하지
않는다.

counter 에서 1,131,968개, PSNR −0.022 dB 로 고정 θ = 4.0 의 1,221,908개보다
Gaussian 이 7.4% 적다. 학습 중 φ 는 step 1,500 에서 1.157, step 13,500 에서
1.220 으로 증가했다. 같은 씬, 같은 block 을 수렴 체크포인트에서 직접 측정한
φ 는 1.555 여서, 사용한 근사식이 21% 낮게 추정한다. 코드 주석에 이 식이 33개
조건에서 20% 안에 맞았다고 기록되어 있어 알려진 정확도 범위다.
